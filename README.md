**Комплексная лабораторная работа №1 · Методы разработки программного обеспечения**

Три реализации одного каталога на C++: линейная, с динамической переменной и модульная. Работа включает разработку программ и метрическую оценку по методическим указаниям преподавателя.

## Возможности

- Добавление автомобиля и сохранение записи в бинарный файл `cars.dat`.
- Просмотр записей в таблице с заголовками.
- Поиск по марке, модели, кузову и сегменту — по подстроке с учётом регистра.
- Поиск по году выпуска и цене — по включительному интервалу.
- Проверка пустого ввода, длины строк, числовых значений и границ интервалов.

## Исходные файлы

| Реализация | Файлы | Организация |
| --- | --- | --- |
| Линейная | [linear.cpp](lab1/linear.cpp) | Вся обработка в `main()` |
| С указателями | [pointers.cpp](lab1/pointers.cpp) | `Car*`, выделение через `new`, освобождение через `delete` |
| Модульная | [main.cpp](modular/main.cpp), [car.h](modular/car.h), [functions.h](modular/functions.h) | Меню, структура и функции разделены по файлам |

В модульной версии `car.h` содержит структуру `Car`, а `functions.h` — объявления и реализации функций. Единственный компилируемый файл этой версии — `main.cpp`.

## Данные автомобиля

| Поле | Тип | Ограничение ввода |
| --- | --- | --- |
| Марка | `char[30]` | 1–29 байт |
| Модель | `char[30]` | 1–29 байт |
| Год выпуска | `int` | 1886–2026 |
| Цена | `int` | Положительное число |
| Кузов | `char[20]` | 1–19 байт |
| Сегмент | `char[10]` | 1–9 байт |

Записи хранятся в виде бинарных структур. Файл создаётся в рабочей папке программы. Длины массивов заданы в байтах; для демонстрации таблицы используются латинские названия.

## Сборка и запуск

Для линейной или указательной версии достаточно соответствующего `.cpp`. Для модульной версии в одну папку проекта копируются `main.cpp`, `car.h` и `functions.h`. В IDE собирается и запускается выбранная реализация.

Ручная сборка GCC из корня репозитория:

```powershell
g++ -std=c++17 lab1\linear.cpp -o linear.exe
g++ -std=c++17 lab1\pointers.cpp -o pointers.exe
g++ -std=c++17 modular\main.cpp -o modular.exe
```

Главное меню: `1` — добавить, `2` — показать все записи, `3` — поиск, `0` — выход. В меню поиска `0` возвращает в главное меню.

## Проверка программ

Все три реализации собраны GCC с параметрами `-std=c++17 -Wall -Wextra -pedantic` без предупреждений. Проверены добавление записи, табличный просмотр, четыре поиска по подстроке и два поиска по интервалу, включая совпадение с границами.
